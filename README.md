# 🌙 Estudo de Lua & Mini Projeto

Repositório dedicado aos estudos práticos da linguagem **Lua**, abordando desde estruturas básicas até conceitos avançados de metatables e orientação a objetos com tabelas.

---

## 📂 Conteúdo do Repositório

- **`main.lua`**: Introdução e primeiros passos com a linguagem.
- **`string.lua`**: Manipulação e formatação de textos/strings em Lua.
- **`tables.lua`**: Criação, iteração e manipulação de tabelas (listas e dicionários).
- **`metatables.lua`**: Conceitos de metamétodos, metatables e sobrecarga de operadores.
- **`inventario.lua`**: Módulo/sistema de inventário em Lua.
- **`mini_projeto_final.lua`**: Mini projeto prático de sistema de batalha por turnos integrando metatables (`__add`, `__tostring`), controle de fluxo e cálculos de combate.

---

## 🚀 Como Executar

Certifique-se de ter o [Lua](https://www.lua.org/) instalado em seu sistema.

Para rodar qualquer um dos scripts:

```bash
lua mini_projeto_final.lua
```
